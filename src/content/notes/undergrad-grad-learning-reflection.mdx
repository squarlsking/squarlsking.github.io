经过大学三年的学习，对本科学习与研究生阶段，我有了一些新的感悟。

## 本科阶段的 GPA

大概可以概括为三点：**好好上课，系统化梳理知识点，加上与老师搞好关系。**

上课认真听，是为了方便后边系统化梳理知识点。我喜欢记笔记，再配上一丁点预习和复习。（好吧，实际上几乎不预习——大家还是一定要好好预习。）

所谓系统化梳理，就是在 PPT、AI、练习题和课本等资源下，把每章知识点的结构、章与章之间的结构、以及章内知识点的结构梳理清楚。这可以借鉴我自己的操作系统复习笔记；它和后文提到的论文 *organize*，其实是同一套能力。

除了考试本身，与任课老师保持积极、正常的沟通，认真完成实验、作业和报告，同样非常重要。这些「脏活累活」往往直接影响平时成绩，也影响老师对完成质量的判断，很大程度上塑造了 GPA 的成绩分布。大家一定要提前 survey 一下选课老师，问问学长学姐老师好不好。

## 科研与高校教育

接下来，我想谈谈自己从大二进入实验室以来，对科研与高校教育形成的一些理解和反思。我会先谈国内外高校教育的粗线条理解，再展开自己喜欢的教育方式、在这种环境下如何做科研学习，最后小小介绍一下志向。

### 毕业表现的概念框架

无论国内还是国外，一个学生最终能够取得怎样的表现，都不可能完全归功于学校，也不能只归因于个人天赋。为了方便理解，我暂时把毕业表现抽象为几个因素共同作用的结果：

<div class="note-formula">
  <strong>毕业表现</strong> = 入学能力 + 家庭背景 + 同伴影响 + 学校培养 + 个人主动性
</div>

这不是精确公式，而是一个分析框架。它大致对应三个层面：

- **初始条件**：入学时的能力、家庭背景和过去接受的教育
- **外部环境**：学校制度、教师、导师、同伴、课程和项目资源
- **个人能动性**：主动做出的选择、投入的时间，以及探索和反思能力

一个人的成长，是这三者长期交互的结果。

### 筛选型大学与培养型大学

如果把不同大学的主导逻辑简化成两种理想类型，可以分别称为：**筛选型大学**与**培养型大学**。

所谓筛选型大学，并不是说学校完全不培养学生，而是它更擅长通过考试、成绩、排名和机会分配，不断识别原本就比较优秀、适应规则或主动性较强的学生。它的基本逻辑更接近：招入一批学生，通过课程和考核继续筛选，让其中最主动、最适应体系的人获得更多发展机会。

培养型大学也会严格筛选生源，但入学之后会更主动地把有利于成长的环节嵌入制度：挑战性的课程与真实项目；写作、展示和讨论；持续的导师反馈；本科科研与实践机会；小型学习共同体；反复修改和接受质疑的过程。它的主导逻辑更接近：不仅寻找优秀学生，也通过相对稳定的机制，让学生在几年中发生结构性变化。

部分国内高校更偏向前一种逻辑；部分优秀的美国老牌研究型大学，则在后一种逻辑上积累了更成熟的制度经验。当然，现实中的大学并不会完全属于其中一种——美国大学同样存在水课、官僚主义和放养；中国也有培养非常扎实的院系、荣誉项目、实验室和导师。不同学校、不同专业，甚至同一个学院的不同课题组之间，都可能差异很大。

如果只考虑深圳大学，我觉得它大概处在两种模式之间。我个人喜欢比较自由松散的形式，所以挺喜欢平时上课难度不高、期末突袭也能拿到还可以 GPA 的学习环境——这样我就能有时间去看看外界的世界，比如科研、实习等等。（虽然我没有实习过，哭。）

### 个人化培养系统

结合自己从大二结束到大三暑假的科研生活，我逐渐形成了一个不太成熟、但对很重要的理解。一个比较理想的个人化培养系统，大概可以概括为：

<div class="note-formula">
  <strong>个人化培养系统</strong> = 好导师 + 小型同伴圈 + 真实项目 + 公开知识资源 + AI 辅助探索
</div>

导师和同伴圈提供不同层次的反馈；真实项目为学习提供具体问题、约束和检验标准；公开知识资源与 AI 则降低进入陌生领域的门槛，让探索更自由。

但环境不等于结果。只有学生主动探索，并通过反馈、执行和总结形成闭环，这些资源才能真正转化为研究能力。

## 我的弯路

我入组不算晚，但真的浪费了很多时间，也走了很多弯路。最开始看的是 3DGS 相关论文——超级难：既不知道一篇论文该怎么读，也没有同方向师兄可以随时请教，整个人都很迷茫。

我花了很久学习 3DGS、MPM，也读过不少不同方向的论文，包括图形学、三维重建、几何、policy learning 以及 agentic system 等。阅读范围看起来很广，但整体比较发散，很多方向都没有真正形成深入、稳定的认识。

现在回头看，问题不只是「看得不够多」，更核心的是我没有形成组织这些知识的方法：不知道怎样梳理论文关系，也不清楚该如何抓住一篇论文的 motivation、核心 insight 和具体贡献。阅读往往是孤立的——今天一篇，过几天另一篇，看完很快就忘，也很难感受到理解在积累。因为长期缺少可见产出和正反馈，那段时间其实非常痛苦。

当时导师要求每周交周报，但我经常不敢发，因为连自己这一周做了什么、得到什么结论都说不清楚，后来甚至逐渐不再提交。这一点我现在需要严肃批评自己：**和导师保持积极、稳定的沟通非常重要。** 最近我也在尝试重新恢复周报，让研究过程重新变得可观察、可总结、可反馈。

## 做好科研的四步

我最近渐渐意识到：要做好科研，首先要读懂论文，然后有自己的思考，再需要外部的 feedback，最后执行验证、总结并更新认知。

### 1. 读懂论文

一篇论文最核心的内容，可以从四个方面理解：

- **Motivation**：为什么要研究这个问题？现有方法有哪些不足？为什么值得解决？开创性工作往往更宏观，增量式工作则更具体，可能针对局限、假设、失败场景或应用边界。
- **Insight**：作者形成了什么关键认识？为什么据此设计的方法可能有效？它可能来自数学/物理直觉、实验现象，或对数据、任务结构与已有方法局限的重新理解。
- **Method**：如何把关键认识落实为具体方法、模块和训练流程？
- **Experiment**：如何在明确的 task 和 setting 下验证核心论点？实验支持了哪些结论，又有哪些结论并没有被充分验证？

除此之外，还应该明确它的 Task、Setting 和 Contribution。否则即便两篇论文表面上都在解决类似问题，也可能因输入输出、数据条件或评价标准不同而无法直接比较。

### 2. 形成思考

真正的阅读不能停留在「作者做了什么」，还要追问：

- 这个问题为什么重要？
- 作者的方法依赖哪些假设？
- 哪一个模块是真正关键的？
- 方法在哪些场景下可能失效？
- 如果 Task 或 Setting 变化，原本的 insight 还成立吗？
- 后续论文究竟修改了什么，又保留了什么？

这样才能把零散论文抽象成结构化的研究地图。大量阅读和思考未必立刻产生可发表的 idea，但能帮助我们发现已有工作的局限、适用边界和未解决问题，为后续提出研究问题创造条件。

### 3. Idea 必须经过多层反馈

初步 idea 形成后，下一步非常重要的是获得反馈。脑中看似完整的 idea，一讲给别人听，往往马上暴露问题：问题是否真的存在？与已有工作比新在哪里？Motivation 和 method 是否对应？Insight 能否解释方法为何有效？实验是否足以验证核心假设？在现实资源和时间下是否可做？

科研反馈不是单一来源，而是一套分层系统：

- **导师**：高层次反馈——方向是否值得做、问题在领域中的位置、贡献是否足够、该继续还是及时调整。导师不太可能持续参与每个工程细节，也不可能随时提供高频反馈。
- **小型同伴圈**：不断澄清问题、检查逻辑、交换相关工作，并校准进度与理解水平。再次向导师汇报时，问题通常已被整理得更清楚。
- **AI**：即时、低成本的辅助反馈——解释概念、梳理论文、检查表达、模拟提问、拆解任务。但它不能完全替代有经验的研究者对方向价值与学术贡献的判断。

### 4. 周报和 PPT 是反馈的载体

获得反馈之后，还需要通过总结更新自己的研究状态。我目前比较认可的是周报和 PPT。

PPT 适合组织论文之间的关系。最近我喜欢这样整理：先找到一篇有代表性的 base 工作，再观察后续论文分别针对什么 Task、Setting 或 Motivation 修改；它们提出了哪些新 Insight，又通过什么 Method 解决问题。这样一来，论文就不再是孤立文章，而能串成有发展脉络的研究路线。更具体的汇报写法，见 [实验室汇报 PPT 规则怪谈](/notes/lab-ppt-report-guaitan/)。

周报则有两方面作用。一方面，它是与导师稳定沟通的工具——即使本周没有好实验结果，也可以说明：尝试了什么、确定了什么、排除了什么、当前卡点、下一步如何推进、有哪些问题需要导师判断。另一方面，它也是对自己研究状态的调控：迫使我们回头观察，这一周究竟是在真正减少不确定性，还是只是在漫无目的地阅读和忙碌。

计划没有完全完成并不可怕。科研任务本来就很难准确估时。更重要的是解释原因：任务比预期复杂、依赖条件未满足、方向发生变化，还是自己出现了拖延。只有不断观察计划与现实的偏差，下一周安排才会越来越合理。

## 几条建议

针对上面的个人化培养系统，结合目前有限的科研经历，我也总结出一些建议：

1. **一定要养好身体。** 身体状态不是科研之外的事，而是科研系统的一部分。研究生生活是几年，不是期末冲刺——找到最符合自己的科研规划。
2. **处理好与导师、师兄师姐的关系。** 他们提供非常重要、且不同层次的 feedback。「处理好」不只是让别人喜欢自己，更重要的是：主动汇报而不是等人追问；遇到问题及时提出而不是独自卡几个月；尊重对方时间，提前整理问题；对建议及时回应并说明进展；逐渐建立「积极、可靠、愿意推进事情」的印象。其余人际关系，建议进一步阅读《山东人的自我修养》。
3. **一定要反思、总结，明确进度和未来要做什么。** 粒度要细，不然会不懂自己到底往哪里走。
4. **建立个人知识与实验资产**——文献地图、实验经验等等。
5. **学会高效汇报**——详情见 [PPT 规则怪谈](/notes/lab-ppt-report-guaitan/)。
6. **自由探索必须有收敛点。**

## 志向

<blockquote class="note-pullquote">
  <p>我要做一个 know everything about something，know something about everything 的人。</p>
</blockquote>

同时，我要成为我们组里「大师兄」一样的人。

这里的大师兄，不只是入组最早、年龄最大，也不是负责催进度和解决所有电脑报错的人。我希望自己能够：

- 帮助新人理解研究方向
- 把宏观问题拆解成可执行的小任务
- 分享论文、代码和实验经验
- 给其他同学提供小而频繁的 feedback
- 连接不同项目和不同研究方向
- 帮助组内形成更加积极、开放的学术氛围

但成为大师兄需要一个逐渐成长的过程。

**第一步永远是先把自己的研究、时间和生活管理好。** 只有自己能够稳定推进，才有能力真正帮助别人。在此基础上，带领和帮助其他同学，也会反过来训练我的能力：为了解释问题，理解必须更清晰；为了拆解任务，必须学会判断优先级与难度；为了组织小项目，需要培养沟通、协调和研究管理能力。同时，这也让我接触更多研究方向，拓宽知识面，并认识更多优秀、有趣的人。

不过我要提醒未来的自己：优秀的大师兄不是替所有人干活，而是帮助大家逐渐具备独立解决问题的能力。

我希望自己未来不仅能做出属于自己的研究，也能成为课题组中的一个知识节点、反馈节点和连接节点。这大概就是我目前对准研究生生活，以及未来研究生生活最期待的样子。
